# Changelog

## 1.1.0 (2026-10-12)

First stable release.

### Added
- `forge new`: create projects from templates, with `--feature` overlays, interactive prompts, and opt-in `--git` / `--install` steps.
- `express-api` template: Express 5 + TypeScript, zod-validated config, helmet, health check, graceful shutdown, tests, ESLint, optional hardened multi-stage Docker image.
- `forge add`: add `ci` and `scan` features to existing repositories, with detection of provider, package manager, branch, Node version and Dockerfile.
- Merge strategies `line-set`, `json-merge` and `yaml-merge` (comment-preserving), so shared files are extended, never clobbered.
- CI pipeline model with GitHub Actions and GitLab adapters. Security checks: secrets, dependencies, SAST, IaC and container scanning. GitHub actions are pinned to full commit SHAs resolved from upstream and at least 14 days old; pinned inputs are verified against each action's `action.yml`.
- `forge doctor`: 19 rules, waivers with required justification, `--fix` through the same transactional engine, `--fail-on`, text/JSON/SARIF output.
- Documentation: authoring guide, security model, security review, rule reference (generated), troubleshooting guide covering every error code.
- Release workflow publishing to npm with provenance; cross-platform and audit workflows; Forge's own CI and security workflows are generated by Forge.

- `forge update`: bring a project up to date with the templates and features it was generated from, keeping every edit you made. Content-driven (so refreshed pins and generator fixes are picked up without a version bump), with `--dry-run --diff`, `--check` (exit 8), `--partial`, `--force` and `--prune`.
- Exit code 8: `forge update --check` found the project behind.
- The transactional applier can now delete files (backed up and restored on rollback).


### Engine guarantees
- Plan/apply with hash-based ownership: idempotent, deterministic, contained, atomic (failure injected at every step in tests), non-destructive.

### Known limitations
- GitLab container scanning is not supported; GitLab security templates report but do not gate.
- `express-api` Docker base image is pinned by tag, not digest.
